# Stakeholder Communication

Operational analytics creates value when findings are translated into clear requests and decisions. This case includes three communication examples with different audiences and purposes.

## 1. Warehouse Escalation for ORD-0007

### Purpose

Request evidence and corrective action for an outbound order with both an SLA breach and a shipment quantity discrepancy.

### Why It Works

- Quantifies the issue: the order shipped four business days after the order date.
- Uses a traceable identifier: `ORD-0007`.
- Distinguishes facts from assumptions: it states that carrier acceptance has not yet been verified.
- Requests evidence: dispatch timestamp, carrier acceptance scan, and explanation of the missing unit.
- Defines follow-up expectations: acknowledgement and initial update timing.
- Establishes an escalation path if no update is received.

### Analytical Value

This message avoids blaming the warehouse before evidence is reviewed. It focuses the warehouse team on the exact records needed for root-cause analysis.

## 2. Freight Forwarder Investigation for PO-FI-1022

### Purpose

Request shipment documentation for an inbound purchase order with a four-unit shortage.

### Why It Works

- Quantifies the discrepancy: 96 received units versus 100 expected.
- Uses a traceable identifier: `PO-FI-1022`.
- References the operational note: pallet counts match but unit counts do not match the packing list.
- Requests records across the chain of custody: invoice, packing list, Bill of Lading, proof of delivery, delivery receipt, and shortage reports.
- Avoids assigning responsibility before comparing documents with receiving records.

### Analytical Value

This communication frames the problem as a reconciliation investigation. It asks for evidence from origin, transit, and delivery before deciding resolution.

## 3. Client Operational Update

### Purpose

Communicate verified operational findings to a client or stakeholder group without overstating conclusions.

### Why It Works

- Separates confirmed SLA breaches from unclassified records.
- Explains that three orders require ship-date verification before SLA classification.
- Communicates inbound shortages with specific PO identifiers.
- States that pallet counts match while unit counts differ.
- Commits to evidence-based follow-up rather than inventing a resolution timeline.

### Analytical Value

The client update builds trust by presenting facts, open issues, and next steps clearly. It avoids unsupported root-cause claims while still showing ownership of the investigation.

## Communication Principles Demonstrated

- Quantify the issue.
- Use traceable identifiers.
- Separate facts from assumptions.
- Request evidence.
- Define next steps.
- Escalate unresolved cases.
- Keep client communication factual and professional.
